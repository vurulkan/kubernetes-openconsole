# Code of Conduct

OpenConsole for Kubernetes follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). Everyone taking part in the
project, in issues, pull requests, discussions and any other project space, is expected to follow it.

## Reporting

If you experience or witness unacceptable behaviour, report it to the maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md):

- For content on GitHub (a comment, an issue, a pull request), use GitHub's **Report content** option; GitHub and the
  repository owner see the report.
- To talk to a maintainer privately, open an issue titled **"Code of conduct: private contact request"** with no
  details in it. A maintainer will reach out to you privately and close the issue.

Reports are handled confidentially. Maintainers who are involved in a report take no part in handling it.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow the
Code of Conduct, and may temporarily or permanently ban a contributor. Decisions follow the enforcement guidelines of
the CNCF Code of Conduct.
