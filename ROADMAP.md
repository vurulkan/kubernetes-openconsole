# Roadmap

Where OpenConsole is heading. It is a direction, not a promise of dates; priorities change with what users report.
Proposals are welcome as issues ([GOVERNANCE.md](GOVERNANCE.md#decisions)). What each release brought is in the
[release notes](https://k8sopenconsole.github.io/release-notes).

## Now

- **Hardening and reliability**: continued security hardening, supply-chain checks of the image and dependencies,
  safer upgrades and backups of the database, cleaner shutdowns.
- **Correctness under load**: per-tab cluster selection, stream and live-event limits, behaviour when a cluster is
  slow or unreachable.
- **Frontend**: clearer error messages, focus and keyboard handling in dialogs and the shell, list performance on
  large namespaces, a consistent Turkish UI, a favicon.

## Next

- Code health: smaller modules for the largest files, a single error and audit helper, broader tests.
- A community around the project: co-maintainers, adopters, contribution guides for common changes.
- Preparing a [CNCF Sandbox](https://www.cncf.io/sandbox-projects/) application.

## Later

Feature ideas are collected as issues; the ones users ask for most move up.
